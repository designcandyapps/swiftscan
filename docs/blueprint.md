# **App Name**: SwiftScan

## Core Features:

- Text Extraction: Optical Character Recognition (OCR): Use AI to extract text from uploaded images or documents.
- Image Upload: Image Upload: Allow users to upload images from their device or paste image URLs.
- Text Display: Text Display: Display the extracted text in a clean, editable text area.
- Download Text: Download Extracted Text: Allow users to download the extracted text in various formats (e.g., .txt, .docx).
- Layout Preservation: Format Preservation Tool: AI tool which reasons whether to attempt preservation of the document's original layout in the output.

## Style Guidelines:

- Primary color: Soft blue (#75A9FF) to convey trust and clarity.
- Background color: Light gray (#F0F4F7) for a clean and professional look.
- Accent color: Teal (#45A29E) for highlighting important actions and elements.
- Body and headline font: 'Inter', a sans-serif font, to maintain a modern, machined, objective, neutral look; suitable for both headlines and body text.
- Use clear, simple icons to represent document actions (upload, download, etc.).
- Maintain a clean and intuitive layout with easy-to-access controls.
- Subtle animations to provide feedback during image processing and text extraction.
